Retail Sales Data Analysis Using Python
Project Overview
This project analyzes sample retail sales data using Python, Pandas, and Matplotlib.
Objectives
- Calculate total sales revenue.
- Identify top-performing products.
- Analyze monthly sales trends.
- Visualize product revenue using charts.
- Practice basic data cleaning.
Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab
Dataset
A small, manually created sample dataset containing product names, prices, quantities sold, dates, and revenue.
Key Skills Demonstrated
- Data manipulation with Pandas
- Data cleaning
- Grouping and aggregation
- Sales analysis
- Data visualization
How to Run
Open "Retail_Sales_Analysis.ipynb" in Google Colab or Jupyter Notebook and run the cells from top to bottom.
Note
This is a beginner practice project. The dataset is illustrative and does not represent actual business transactions.
